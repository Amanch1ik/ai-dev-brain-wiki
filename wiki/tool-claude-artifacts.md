# Claude Artifacts

Песочница Anthropic для запуска сгенерированного кода прямо в интерфейсе Claude. [[simon-willison]] называет её одной из первых широкодоступных платформ для [[concept-vibe-coding]] и образцом безопасной изоляции.

## Содержание

Подход к sandboxing, который хвалит Уиллисон: код исполняется в locked-down `<iframe>`, может грузить **только одобренные библиотеки** и **не может делать сетевых запросов** к другим сайтам. Это резко снижает риск навредить — но и ограничивает возможности: из Artifact нельзя обращаться к внешним API или даже запускать собственные промпты против LLM.

Контраст: инструменты вроде [[tool-cursor]] дают куда меньше защитных ограждений, потому что нацелены на профессиональную разработку.
