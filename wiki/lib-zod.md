# Zod

TypeScript-first библиотека валидации: определяешь **схемы** (от простого `string` до сложных вложенных объектов) и валидируешь ими данные, получая на выходе типобезопасный результат.

## Содержание

```ts
import * as z from "zod";
const User = z.object({ name: z.string() });
const data = User.parse(input); // валидировано И типобезопасно
```

Особенности: ноль внешних зависимостей; Node + все современные браузеры; крошечный (~2kb core, gzipped); иммутабельный API (методы возвращают новый инстанс); статический вывод типов из схемы. Zod 4 — стабилен.

**Почему релевантно агентному кодингу.** Схема-как-источник-истины даёт **быструю точную обратную связь** на границах данных — это ось Detectability в [[concept-ai-risk-assessment]] и «типизированный язык, где сбои очевидны». Валидация на входе — форма «важных проверок локально» из [[concept-ai-friendly-codebase]] (проверки на виду у агента). Единый TS-тип из рантайм-схемы устраняет рассинхрон типов и валидации — меньше классов ошибок, которые агент может внести незаметно.

⚠ Между Zod 3 и 4 есть breaking changes — сверяйся с zod.dev и учитывай [[concept-training-cutoff]].
