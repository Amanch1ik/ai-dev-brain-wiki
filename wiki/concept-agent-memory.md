# Память агента (Claude vs ChatGPT)

Две противоположные философии долговременной памяти LLM. У Claude память — это **инструменты, вызываемые явно**; у ChatGPT — контекст, **автоматически** подставляемый в начало каждого разговора. Разбор [[simon-willison]] (по материалам Shlok Khemani).

## Содержание

**Claude memory** (два свойства):
1. Каждый разговор стартует с чистого листа — без предзагруженных профилей и истории; память активируется только при явном обращении.
2. Recall идёт по **сырой** истории переписки — никаких AI-саммари или сжатых профилей, только поиск по реальным прошлым чатам.

Реализована как два tool-вызова (Уиллисон подтвердил, запросив список инструментов у модели):
- `conversation_search` — поиск по прошлым разговорам ради релевантного контекста;
- `recent_chats` — недавние чаты с сортировкой/пагинацией/фильтром по проекту.

Плюс — **прозрачность**: память видна как явные tool-вызовы, понятно когда и как модель лезет в прошлый контекст. Это прямое проявление [[concept-llm-agent]] («долговременную память лучше всего реализовывать через дополнительный набор инструментов»).

**ChatGPT memory** — иначе: модель не решает через инструменты, система сама вставляет детали прошлых разговоров в начало каждого чата. Уиллисону это не нравится (меньше контроля над контекстом). Смягчающая деталь: всплывают только сообщения пользователя, не ответы ассистента — значит «протухший» ответ не тащится в новый чат.

**Почему это важно для практики.** Память угрожает подходу [[method-context-management]] «clean slate»: если начинаешь свежий чат, чтобы выкинуть плохой контекст, автоматическая память может притащить его обратно. Прозрачная, инструментальная модель Claude эту проблему снимает.

⚠ Обновление из статьи: Anthropic анонсировала доп. память для Team/Enterprise («Generate memory of chat history») — ближе к модели OpenAI, но редактируемая и с отдельной памятью на каждый проект.
