# OKLCH — цвет для дизайн-систем

Новая CSS-нотация цвета (`oklch(L C H / a)`) из CSS Color 4: `L` — *перцептивная* светлота (0–1), `C` — chroma (насыщенность), `H` — тон (0–360). Инструмент премиальной палитры в [[method-premium-creative-web]].

## Содержание

Разбор Evil Martians — почему уходить с RGB/HSL:
1. **Авто-генерация палитры** — задаёшь формулу и пару цветов, вся система генерируется автоматически.
2. **Wide-gamut P3** — новые дисплеи (Apple) показывают больше цветов, чем sRGB; OKLCH их адресует.
3. **Лучше для модификаций** — перцептивная светлота: нет неожиданных результатов, как у `darken()` в Sass.
4. **Лучше a11y** — предсказуемая светлота → предсказуемый контраст.
5. **Человекочитаемость** — по числам понятно, что за цвет (в отличие от hex `#ca0000`).

Пример: `oklch(0.45 0.26 264)` — синий; `oklch(1 0 0)` — белый; `oklch(0 0 0 / 50%)` — чёрный 50%.

**Грабли:** не все комбинации L/C/H отображаются на любом мониторе (браузер ищет ближайший — проверяй пикером oklch.com); экосистема ещё молодая. Практика: **Tailwind v4** ([[lib-tailwind]]) перешёл на OKLCH-палитру; для body-текста целься в контраст по APCA. Часть арт-дирекции (палитра) в премиум-вебе.
