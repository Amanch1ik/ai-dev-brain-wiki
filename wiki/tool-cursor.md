# Cursor

AI-редактор кода (форк VS Code) со встроенным агентным режимом. Именно Cursor Composer + Sonnet фигурирует в оригинальном описании [[concept-vibe-coding]] у [[andrej-karpathy]].

## Содержание

В твите-первоисточнике Карпатый вайбкодит через Cursor Composer с моделью Sonnet, разговаривая с ним голосом (SuperWhisper) и почти не касаясь клавиатуры («Accept All всегда, диффы не читаю»).

[[simon-willison]] отмечает, что Cursor изначально задумывался для профессиональных разработчиков и имеет **гораздо меньше защитных ограждений** (safety rails), чем песочница [[tool-claude-artifacts]] — то есть при вайбкодинге в Cursor выше риск навредить (сетевые запросы, доступ к данным, секреты).

### Как устроен сбор контекста
По разбору Нетологии: Cursor **индексирует** кодовую базу (режет на чанки — функции/блоки), строит **embeddings** и векторную БД для **семантического поиска** (найти «где обрабатываются ошибки» по смыслу, а не по тексту), затем на запрос делает **retrieval** — шлёт в модель не весь проект, а релевантное: текущий файл + связанные по импортам/вызовам + фрагменты из semantic search. При правках индекс перестраивается. Это конкретизация [[method-context-management]] на уровне инструмента.

⚠ Конкретные фичи/цены Cursor быстро меняются — проверяй на официальном сайте.
