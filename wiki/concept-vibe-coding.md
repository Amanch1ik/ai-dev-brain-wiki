# Vibe coding

Стиль разработки, при котором софт строят с помощью LLM, **не читая написанный им код**. Термин ввёл [[andrej-karpathy]] 6 февраля 2025; уточнённое рабочее определение дал [[simon-willison]].

## Содержание

Карпатый описал это так: «новый вид кодинга, где ты полностью отдаёшься вайбам… и **забываешь, что код вообще существует**». В его практике: `Accept All` всегда, диффы не читаются, ошибки копипастятся в модель без комментариев, при неустранимом баге — обход или «случайные изменения, пока не пройдёт». Инструменты, которые он называет: Cursor Composer + Sonnet ([[tool-cursor]]) и голосовой ввод SuperWhisper.

Ключевое разграничение Уиллисона: **vibe coding ≠ любое использование LLM для кода**. Если ты сгенерировал код, но потом прочитал, протестировал и можешь объяснить, как он работает, — это уже [[method-ai-assisted-programming]], а не вайбкодинг. Уиллисон формулирует vibe coding как «building software with an LLM without reviewing the code it writes».

### Когда вайбкодить нормально

- **Низкие ставки** — прикинь вред от багов/уязвимостей, особенно если софтом будут пользоваться другие.
- **Безопасность и секреты** — следи за API-ключами и приватными данными; чтобы не утекли, нужно понимать, как работает код.
- **Деньги на кону** — известны истории, где вайбкод против платного API без лимита биллинга давал счета на тысячи долларов.
- **Хороший сетевой гражданин** — запросы к чужим сервисам повышают на них нагрузку.

### Ценность

Снижает почти до нуля начальный барьер входа в программирование; для опытных — быстрый способ нарастить интуицию, что LLM могут и чего не могут. Безопасный вайбкодинг для новичков начинается с песочницы — образцовый пример изоляции даёт [[tool-claude-artifacts]] (код в locked-down `<iframe>`, только одобренные библиотеки, без сетевых запросов). Cursor и подобные инструменты профессионального класса имеют меньше защитных ограждений.

### Вайбкодинг как способ учиться

Уиллисон вайбкодил ещё до того, как Карпатый дал этому имя: его репозиторий `simonw/tools` — десятки HTML+JS и Python-приложений, каждое построено промптингом LLM. Вывод: кидать в модель абсурдные идеи и вайбкодить, пока «почти работает», — реально ускоряет наработку интуиции. При этом отдельные фрагменты бывают «pure vibe-coding» даже внутри серьёзного процесса — см. пример сессии в [[tool-claude-code]], где часть кода он не читал.
