# Паттерны агентных workflow

Пять композируемых паттернов из production-опыта Anthropic — от простого к сложному, поверх [[concept-augmented-llm]]. Не догма: комбинируй, усложняй **только** когда это измеримо улучшает результат.

## Содержание

### 1. Prompt chaining
Задача разбита на последовательность шагов; каждый LLM-вызов обрабатывает вывод предыдущего. Можно вставлять программные «gates» (проверки) между шагами. **Когда:** задача чисто раскладывается на фиксированные подзадачи; меняешь латентность на точность. *Пример: написать outline → проверить критерии → написать документ.*

### 2. Routing
Классифицирует вход и направляет в специализированную ветку. **Когда:** есть различимые категории, лучше обрабатываемые раздельно, и классификация точна. *Пример: простые вопросы → дешёвая модель (Haiku), сложные → мощная (Sonnet); типы обращений в саппорт → разные процессы.*

### 3. Parallelization
Две вариации: **Sectioning** (независимые подзадачи параллельно) и **Voting** (один и тот же запрос несколько раз ради разнообразия/уверенности). **Когда:** подзадачи параллелятся ради скорости или нужно несколько перспектив. *Пример: один инстанс отвечает, другой проверяет на недопустимый контент (guardrails); несколько промптов ищут уязвимости в коде (voting).* — основа adversarial-подхода в [[pattern-writer-reviewer]].

### 4. Orchestrator-workers
Центральная LLM динамически дробит задачу, делегирует worker-LLM и синтезирует результаты. Отличие от parallelization — подзадачи **не предопределены**, их определяет оркестратор по входу. **Когда:** нельзя предсказать подзадачи. *Пример: правки в множество файлов; многоисточниковый поиск.* — ядро [[concept-agentic-engineering]].

### 5. Evaluator-optimizer
Один LLM генерирует ответ, другой в цикле оценивает и даёт фидбек. **Когда:** есть чёткие критерии оценки и итеративное уточнение приносит измеримую пользу. *Пример: литературный перевод; сложный поиск, где evaluator решает, нужны ли ещё раунды.*

> Ключ к успеху — измерять и итерировать; добавлять сложность только когда она демонстрируемо помогает.
