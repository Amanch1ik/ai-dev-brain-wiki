# ModelScope (魔搭)

Платформа моделей от Alibaba — китайский аналог Hugging Face. Даёт **бесплатный API-Inference** к моделям китайской экосистемы (Qwen, DeepSeek, Qwen-Image и др.). Годится как песочница для экспериментов, не как прод-бэкбон.

## Содержание

### Что это и зачем
Хаб моделей + inference-платформа. OpenAI-совместимый endpoint — подключается в код одной строкой (`base_url` + токен), без переписывания клиента. Полезно, когда нужно бесплатно погонять Qwen/DeepSeek или сгенерировать картинки через **Qwen-Image**.

### Бесплатный тариф — реальные цифры
- **Без карты.** Регистрация + **привязка Alibaba Cloud + real-name verification** — главный барьер: верификация часто требует китайский телефон/ID, из СНГ может стать стеной.
- Лимиты: **2000 запросов/сутки** всего, **500 на модель**. Превышение → `429`. Сброс раз в 24ч, без переноса остатка.
- Не «сотни бесплатных API», как пишут в рекламных постах, — реально API-Inference-enabled моделей **десятки** (по одному источнику ~54), остальное — веса на скачивание.

### Подключение (OpenAI-совместимо)
```python
from openai import OpenAI
client = OpenAI(
    base_url="https://api-inference.modelscope.cn/v1",  # ⚠ проверить актуальный base_url в доках
    api_key="<MODELSCOPE_TOKEN>",
)
r = client.chat.completions.create(
    model="Qwen/Qwen2.5-72B-Instruct",  # ⚠ точные id — из каталога Models → фильтр API-Inference
    messages=[{"role": "user", "content": "..."}],
)
```
Найти дёргаемые модели: сайт → раздел **Models** → фильтр **API-Inference**.

### Грабли и риски
- **Данные уходят на серверы Alibaba (Китай)** — не отправлять чувствительное; учесть латентность из региона.
- Лимит 2000/сутки — для pet-проекта ок, для продакшена нет.
- id моделей и base_url меняются — сверяться с доками, не хардкодить вслепую (`⚠ проверить`).
- Vision/image-модели требуют своих форматов запроса — читать карточку модели.

### Когда брать / не брать
- **Брать:** бесплатная песочница для Qwen/DeepSeek; **Qwen-Image** для генерации картинок (например, фото блюд для лендинга вместо типографики).
- **Не брать:** как основной бэкенд агента/прода — тут сильнее и стабильнее собственный Claude ([[tool-claude-code]] / Claude API); ModelScope — дополнение, не замена.
