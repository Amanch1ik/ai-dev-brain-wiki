# AI Dev Brain — wiki

Инженерная база знаний, которую ведёт AI-агент по письменной конституции.
Не свалка заметок и не awesome-list: источники вычитываются целиком, разбираются
на сущности, превращаются в связанные страницы и попадают в оглавление.

Домены: вайбкодинг и агенты, мультиагентная оркестрация, WebGL и Three.js,
моушен-дизайн, методики разработки.

---

## Что здесь опубликовано

Это **вики-половина** базы — 86 страниц авторского синтеза.

Папка с сырьём (`raw/`, 48 полных текстов чужих статей и документаций)
**намеренно не опубликована**: это чужая работа, и републиковать её целиком
неправильно. В блоках `## Источник` на каждой странице остались имя автора,
название и дата — ссылки вида `raw/xxx.md` указывают на приватную копию
источника и в этом репозитории не разрешаются. Первоисточник всегда назван,
идите к автору напрямую.

## Как это работает

```
   источник                обработка                     результат
   ────────                ─────────                     ─────────

   Web Clipper  ─┐
   defuddle     ─┼──▶  Clippings/  ──┐
                 │                    │
   NotebookLM   ─┘                    ├──▶  raw/  ──▶  вычитать целиком
                                      │   приватно     выделить сущности
   свои заметки ──────────────────────┘                        │
                                                               ▼
                                                          wiki/*.md
                                                       страница = сущность
                                                       связи взаимные
                                                               │
                                                               ▼
                                                          index.md
```

`raw/` неприкосновенна: единственное допустимое изменение источника — строка
`<!-- processed: YYYY-MM-DD -->`, чтобы не обрабатывать дважды.

## Канон страницы

```markdown
# Название

Summary в 1-2 строки — что это, зачем, когда применять.

## Содержание
Синтез, не пересказ. Для библиотек: назначение, установка, ключевые API,
типичное применение, грабли, альтернативы.

## Связано с
- [[lib-xxx]] — альтернатива / зависимость / используется вместе

## Источник
- автор, название, дата, URL
```

Связи только **взаимные**: если A ссылается на B, то B ссылается на A.
Поэтому граф замкнут, а не рассыпается на острова.

## Дисциплина

Полностью — в [AGENTS.md](AGENTS.md). Главное:

- Противоречия источников фиксируются явно: «по данным A — …; по данным B — …».
  Молча выбрать сторону нельзя.
- Неподтверждённая сигнатура, команда или цифра помечается `⚠ проверить`
  со ссылкой на источник.
- Выдумывать связи, API или цитаты запрещено.
- Каждая сессия заканчивается проверкой: битых ссылок 0, невзаимных связей 0.

## Как читать

Открыть [`index.md`](index.md) — оглавление разложено по темам. Либо смотреть
`wiki/` напрямую: префикс в имени файла говорит, что внутри.

Файлы — обычный Markdown с wikilinks `[[имя-файла]]`. На GitHub такие ссылки
не кликабельны; чтобы граф работал, склонируйте репозиторий и откройте папку
как vault в [Obsidian](https://obsidian.md).
